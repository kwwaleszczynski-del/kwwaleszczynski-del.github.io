Grid connection studies and non-firm capacity on Polish MV/110 kV feeders

Steady-state and N-1 study of a synthetic Polish 110/15 kV GPZ and four radial 15 kV feeders built from catalogue conductor data, solved with a polar Newton-Raphson Ybus power flow: hosting capacity under unity power factor, cos-phi(P) and Q(U), annual reactive energy, export caps with a battery, and cable pooling under N-1.

On a 14.2 km overhead feeder cos-phi(P) and Q(U) lift hosting capacity from 2.30 MW to 3.21 and 3.11 MW, but cost capacity on a thermally limited cable feeder; a 70 % export cap curtails 1.78 % of PV energy, and pooling wind behind the same 21.54 MW connection carries 1.96 times the energy of firm PV.

res-asset-kpi: KPI library for PV, wind and BESS

An open-source Python library on PyPI, with a Zenodo DOI, for the indicators asset managers report every month: PR and weather-corrected PR, contract availability for PV, wind (IEC 61400-26 categories) and batteries, the budget-to-actual energy bridge, power curves and AEP, MTBF/MTTR and Crow-AMSAA, SoC-corrected round-trip efficiency, cycles, capacity tests with uncertainty and contract damages set in YAML.

Extracted from six analysis projects and reproducing their results exactly (41 checks over about a million values, largest relative difference 1.3e-13); a hand-worked test for every formula, Hypothesis property tests, mypy strict, CI on Python 3.11-3.13.

  • PyPI package
  • IEC 61724-1 / 61400-26
  • asset management

pse-opendata: Python client for PSE data

An open-source library for the public data of the Polish TSO: 16 reports plus the legacy CSV export since 2009 as tidy pandas frames with explicit interval times in UTC and local time, monthly Parquet cache aware of PSE's late corrections, and a CLI.

103 offline tests on recorded responses plus live checks against PSE's API description; documents pitfalls such as DST labels, the 100,000-row cap and pagination that drops rows.

  • Python library
  • pandas
  • PSE API
